# בוט מסחר + אפליקציה לטלפון — Alpaca (חשבון מדומה)

הבוט רץ בענן של GitHub (בחינם) פעמיים בכל יום מסחר, מתחבר לחשבון ה-Paper שלך ב-Alpaca, בונה תיק מתוך רשימת מניות ה-Buy שלנו, וקונה ומוכר לפי חוקים קבועים.
האפליקציה בטלפון מציגה את התיק, העסקאות וההשוואה למדד S&P 500.

> חשבון מדומה בלבד. אין כאן ייעוץ השקעות. מעבר לכסף אמיתי רק אחרי בדיקה של חודשיים, ורק בהחלטה שלך (ראה סעיף 9).

---

## 1. מפתחות API ב-Alpaca (2 דקות)
1. נכנסים ל-https://app.alpaca.markets ובוחרים בחשבון **Paper** (למעלה משמאל).
2. בדף הבית, בצד ימין: **API Keys → Generate New Keys**.
3. מעתיקים את **Key ID** ואת **Secret Key**. ה-Secret מוצג פעם אחת בלבד.
4. **לא לשלוח את המפתחות בצ'אט** (גם לא לי). הם נכנסים רק ל-GitHub, בשלב 3.

## 2. מאגר ב-GitHub (5 דקות)
1. פותחים חשבון חינמי ב-https://github.com (אם אין).
2. **New repository** → שם: `stocks-bot` → **Public** → מסמנים **Add a README file** → Create.
   (Public נחוץ כדי לארח את האפליקציה בחינם. המפתחות לא נחשפים, כי הם שמורים כ-Secrets מוצפנים. מה שכן גלוי: התיק המדומה.)
3. **Add file → Upload files** → בוחרים את **כל הקבצים** מה-zip חוץ מ-`trade.yml` (אפשר לסמן את כולם יחד) → **Commit changes**.
   אם GitHub שואל אם להחליף את README.md, מאשרים.
4. **Add file → Create new file** → בשורת שם הקובץ מקלידים בדיוק:
   `.github/workflows/trade.yml`
   (כל `/` שמקלידים יוצר תיקייה אוטומטית) → מדביקים את כל התוכן של הקובץ `trade.yml` → **Commit changes**.

## 3. שמירת המפתחות (Secrets)
במאגר: **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Value |
|---|---|
| `ALPACA_KEY_ID` | ה-Key ID מ-Alpaca |
| `ALPACA_SECRET_KEY` | ה-Secret Key מ-Alpaca |
| `NTFY_TOPIC` | (לא חובה) שם ייחודי להתראות, למשל `ohad-stocks-83jd2` |

## 4. הפעלת האפליקציה
**Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, תיקייה: `/ (root)` → Save.
אחרי דקה-שתיים הכתובת תופיע: `https://<שם-המשתמש>.github.io/stocks-bot/`

## 5. הרצה ראשונה = הקנייה הראשונית
**Actions → Trading bot → Run workflow → full → Run**.
- אם השוק בניו יורק פתוח (בערך **16:30–23:00 שעון ישראל**, בימים שני–שישי) הבוט יקנה מיד 12 מניות.
- אם השוק סגור, הוא רק ישמור תמונת מצב, והקנייה תתבצע אוטומטית בהרצה הבאה.
- אם מופיעה שגיאה בשלב השמירה: **Settings → Actions → General → Workflow permissions → Read and write** → Save, ומריצים שוב.

מכאן הכול אוטומטי: בכל יום מסחר בערך ב-**17:07** (קנייה ומכירה) וב-**21:37** (בדיקת סטופים בלבד) שעון ישראל.

## 6. התקנה בסמסונג S26 Ultra
1. פותחים את הכתובת משלב 4 ב-**Chrome** או ב-**Samsung Internet**.
2. תפריט (⋮ או ☰) → **הוסף למסך הבית / התקן אפליקציה**.
3. האייקון מופיע במסך הבית ונפתח כמו אפליקציה רגילה, בלי שורת כתובת.

## 7. התראות לטלפון על כל קנייה ומכירה (לא חובה)
1. מתקינים את האפליקציה **ntfy** מחנות Google Play.
2. ➕ Subscribe to topic → מקלידים **בדיוק** את השם ששמרת ב-`NTFY_TOPIC`.
3. מעכשיו כל עסקה של הבוט תקפוץ כהתראה. (ב-ntfy כל מי שיודע את השם יכול לראות את ההתראות, לכן כדאי שם ייחודי.)

## 8. שליטה בבוט
- **השהיה:** בקובץ `config.json` (עריכה ✏️ גם מאפליקציית GitHub) משנים ל-`"paused": true`. החזרה: `false`.
- **עצירה מוחלטת:** Actions → Trading bot → ⋯ → Disable workflow.
- **מכירה ידנית מהטלפון:** באפליקציה → הגדרות → מזינים את מפתחות ה-Paper (נשמרים רק בטלפון). אם הדפדפן מאפשר חיבור ישיר ל-Alpaca, יופיע כפתור "מכור" ליד כל מניה. אם לא, אפשר למכור דרך אתר Alpaca.
- **שינוי חוקים:** בקובץ `config.json` (מספר מניות, אחוז סטופ וכו').

## 9. אחרי חודשיים
האפליקציה סופרת לאחור ל"בדיקת החודשיים" ומשווה את התיק ל-S&P 500 באותה תקופה.
המעבר לכסף אמיתי חסום בכוונה וצריך שלושה צעדים ידניים: מפתחות Live חדשים ב-Secrets, `"mode": "live"` ב-`config.json`, ו-Secret נוסף `ALPACA_LIVE_CONFIRM` עם הערך `I-UNDERSTAND`. בלי שלושתם, הבוט נשאר ב-Paper.

## איך הבוט מחליט
- **הרשימה:** כ-180 מניות שאנליסטים דירגו Buy/Strong Buy (ארה"ב + ישראליות דואליות), מ-`universe.csv`.
- **ציון קנייה 0–100**, אותה נוסחה כמו בקובץ האקסל: מגמה 25 · מומנטום 20 · תיקון בריא 20 · תנודתיות נמוכה 15 · פער ליעד האנליסטים 20. מחושב כל יום ממחירי Alpaca.
- **קנייה:** עד 12 מניות בחלוקה שווה, 10% נשארים במזומן. רק ציון ≥60, מחיר ≥$3, תנודתיות ≤90%. בקנייה הראשונית לפחות 2 ישראליות אם יש מתאימות. אחר כך עד 3 קניות חדשות ביום, רק כשמתפנה מקום.
- **מכירה:** ירידה של 8% ממחיר הקנייה · ירידה של 12% מהשיא מאז הקנייה · הגעה ליעד האנליסטים · ציון מתחת ל-35. אחרי מכירה אין חזרה לאותה מניה במשך 10 ימים.
